# XinBlue Podcast RSS Feed

This repo hosts the RSS feed and MP3 episodes for the **XinBlue Podcast**, which Spotify pulls automatically.

- Feed: <https://hanneskannes-com.github.io/xinblue-podcast-rss/feed.xml>
- Cover: <https://hanneskannes-com.github.io/xinblue-podcast-rss/cover.jpg>
- Episodes: served from `/episodes/`

Edits via `tools/upload.py episode <name> --platforms spotify` from the main repo.
